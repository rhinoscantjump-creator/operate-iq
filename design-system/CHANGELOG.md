# Design changelog

## 2026-08-18 — Homepage launch pad

Home hero uses four labeled buttons. Live puzzles show the local streak count; a fourth slot is reserved. Detailed cards remain below.

## 2026-08-18 — WordGuess

Third puzzle renamed from Triad. Twelve shared guesses. Closest unsolved board snaps down next to the keyboard. Teal / amber / muted marks.

## 2026-08-18 — Daily triad

Third puzzle: three five-letter words, eight shared guesses. Teal / amber / muted marks. Mobile type-in sticks to the top, boards stack and snap by closeness, keyboard sticks to the bottom.

## 2026-08-18 — Wordsearch zoom

Fixed viewport around the 12×12. Starts at 1.2× so letters clip the box. Pinch (and wheel) zoom; Play is default for selecting words; Move pans.

## 2026-08-18 — Sudoku phone chrome

On viewports ≤900px, play nav/heading collapse behind a thin pull tab so the existing board and pad sit higher. Pad layout is unchanged.

## 2026-08-18 — Daily puzzle rebuild

Wiped the hub/reference marketing system. Site is now a daily wordsearch + sudoku desk: dark teal tokens kept, game boards and puzzle cards added, leak-map/playbook layout retired.
