## The pattern

New client onboarding fails when intake is scattered across email, PDFs, and ad-hoc spreadsheets. Most boutique firms repeat the same loop:

1. Proposal is signed — then someone **rebuilds the checklist from memory**
2. Documents arrive in **random email threads**
3. Folders are **copied from last year’s client** (and cleaned up badly)
4. Nobody knows if the engagement is **actually ready** to start

The fix is a **single intake route**: trigger → standard checklist → folder pack → CRM status — with a human gate before “Active.”

## What good looks like

| Before | After |
|---|---|
| Kickoff list rewritten per client | One master checklist, cloned per deal |
| “Where’s the folder?” in Slack | Template pack created on signature |
| Status is vibes-based | Active only after readiness check |
| Missing docs chased ad hoc | Timed reminders on open checklist rows |

## Playbooks in this topic

Start with the checklist and the folder pack — they lock together. Intake-form routing (Typeform → HubSpot) comes next for firms that want the form to own step one.

## Guardrail principle

**Automation prepares; humans declare ready.** Never auto-mark a client Active, never auto-copy prior-year confidential files into a new pack, and keep engagement-letter sign-off as a required human step.
